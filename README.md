# 六级精读实验室 · CET-6 Review Hub

将不同套次的六级学习材料整合在**同一个网站、同一套导航、同一个总词库和统一题库**中。学习记录从 2026-10-19 开始，最近更新于 2026-10-25。

## 在线网站

https://immkernel.github.io/cet6-review-hub/

网站主入口是根目录 `index.html`，支持离线打开，不依赖构建工具。GitHub Pages 必须已在 `Settings → Pages` 开启。

## 使用方式

- **学习总览**：全部文章卡片集中呈现。目前有三篇：第二套 AI 与人类工作、第二套不请自来的建议、第三套口音与标准英语
- **文章精读**：三篇文章共用同一个精读模块，可切换、逐段读译文、标记已读
- **核心词汇**：单一总词库，包括全部选词填空备选词、文章高频词和重要搭配；默认显示**所有词**，可搜索、翻词卡、标记掌握、筛选已掌握/未掌握；新增第三套 33 条词汇或搭配（与旧词重复的 `domains`、`spectrum` 沿用原有条目）
- **语法 · 长难句**：全部题材放在原有语法列表，新增 `with + 名词 + doing/done`、两个 `with` 的用法及 `rather than`
- **真题训练**：统一25题，按“全部25题 / 选词填空20题 / 仔细阅读5题”筛选。第二套选词填空为四选一改编，第三套选词填空是原 A—O 十五选一的语境练习；批改和错题统计共用一个系统
- **错题与复习**：统一错题、累计答题、进度导入和导出

新增第三套 Section A（26—35）的纸面答案参考为 **NGFJHMECDB**，具体解释请在“文章精读”“语法 · 长难句”“真题训练”中查看。学习版答案不等于考试机构官方答案。

## 维护原则

1. **不要为每篇文章另建网页专题**。新文章添加到 `index.html` 中的 `articles` 数据，新词加入 `wordbank`，语法归入 `grammar`，试题加入统一 `allQuizzes`。
2. **新词追加到词库末尾**，不要重排旧词。`wordbank` 的数字 `id` 用于保留浏览器中的“已掌握”状态。
3. 不同试卷可能都有第 26—35 题。内部 `num` 必须唯一；显示原试卷题号使用 `paperNo`，同时显示套次。
4. 数据使用原有的 `localStorage` 键 `cet6_reading_lab_v1`，旧版阅读记录、词汇掌握状态与历史答题记录不会因合并丢失。学习记录**仅存在当前浏览器/域名**，不跨设备同步；建议在“错题与复习”中导出 JSON 备份。
5. 每次学习留一份 `records/YYYY-MM-DD.md` 笔记即可，笔记不等于单独网页。
6. 大版本修改前保留 `archive/` 快照。不要将包含个人学习进度的 JSON 文件提交到公开 GitHub。

## 发布

将 `main` 分支根目录的 `index.html` 通过 GitHub Pages 部署（`Settings → Pages → Deploy from a branch → main / (root)`）。提交到 main 后，若 Pages 已启用会自动更新。
