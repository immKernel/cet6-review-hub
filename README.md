# 六级精读实验室 · CET-6 Review Hub

将不同套次的六级学习材料整合在**同一个网站、同一套导航、同一个总词库和统一题库**中。学习记录从 2026-10-19 开始，最近更新于 2026-11-22。

## 在线网站

https://immkernel.github.io/cet6-review-hub/

网站主入口是根目录 `index.html`，支持离线打开，不依赖构建工具。GitHub Pages 必须已在 `Settings → Pages` 开启。

## AI 助手维护规范

**[AGENTS.md](AGENTS.md) 是本仓库的正式 AI 维护规则。** 无论使用 Codex、Claude Code、Copilot 或其他 AI，新增英语学习材料前都应先阅读并遵守它，特别是：**一个网站、一个“所有单词”总词库、统一的语法/题库、旧学习进度不丢失**。

- Claude Code 入口：[CLAUDE.md](CLAUDE.md)
- GitHub Copilot 入口：[.github/copilot-instructions.md](.github/copilot-instructions.md)

## 使用方式

- **学习总览**可一键进入 2026 年 6 月第一套练习或医疗科技汉译英。
- **文章精读**包含 9 个主题，可逐段对照译文、查看考点和标记已读。汉译英先显示中文，再展开英文参考译文。
- **核心词汇**默认显示**所有单词**，支持搜索、翻卡和掌握标记。本次追加 74 个词汇与搭配。选词填空的 `presume` 已在词库中，沿用原词条并补充新例句。
- **语法 · 长难句**新增租金管制、段落匹配、仔细阅读和汉译英的 7 个句式卡片。
- **真题训练**共 58 题，支持按套次或题型筛选。2026 年 6 月第一套包含听力文字复盘 23–25、选词填空 26–35、段落匹配 36–45 和仔细阅读 46–55。第一套素材经学习改写，保留纸面题号及选项字母对应。
- **错题与复习**汇总所有题目的错题与累计答题记录，支持导入和导出进度。

各题解析可在“真题训练”作答后查看。答案与译文供学习参考。

## 维护原则

1. **不要为每篇文章另建网页专题**。新文章添加到 `index.html` 中的 `articles` 数据，新词加入 `wordbank`，语法归入 `grammar`，试题加入统一 `allQuizzes`。
2. **新词追加到词库末尾**，不要重排旧词。`wordbank` 的数字 `id` 用于保留浏览器中的“已掌握”状态。
3. 不同试卷可能都有第 26—35 题。内部 `num` 必须唯一；显示原试卷题号使用 `paperNo`，同时显示套次。
4. 数据使用原有的 `localStorage` 键 `cet6_reading_lab_v1`，旧版阅读记录、词汇掌握状态与历史答题记录不会因合并丢失。学习记录**仅存在当前浏览器/域名**，不跨设备同步；建议在“错题与复习”中导出 JSON 备份。
5. 每次学习留一份 `records/YYYY-MM-DD.md` 笔记即可，笔记不等于单独网页。
6. 大版本修改前保留 `archive/` 快照。不要将包含个人学习进度的 JSON 文件提交到公开 GitHub。

## 发布

将 `main` 分支根目录的 `index.html` 通过 GitHub Pages 部署（`Settings → Pages → Deploy from a branch → main / (root)`）。提交到 main 后，若 Pages 已启用会自动更新。
